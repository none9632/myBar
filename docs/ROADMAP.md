# Roadmap: из бара в систему виджетов

Цель большой задачи — вырастить `myBar` из бара для Hyprland в полноценную
оболочку виджетов и **полностью отказаться от rofi**.

Документ описывает фазы: что делаем, какими файлами, чем проверяем готовность.
Фазы 3–9 после Фазы 2 независимы, порядок можно менять.

---

## Исходная точка

### Что сейчас вызывает rofi

| Скрипт (`~/.config/rofi/scripts/`) | Кейбинд | Что делает |
|---|---|---|
| `appslauncher` | `Super + D` | `rofi -show drun` — запуск приложений |
| `appsmenu` | `Super + Return` | сетка из 5 быстрых ссылок (terminal/messenger/editor/browser/settings) |
| `powermenu` | `Super + P` | lock / reboot / shutdown / suspend / logout |
| `screenshot` | `F11`, `Print` | экран / окно / область через flameshot |
| `filesearch` | — | листалка каталога с иконками по расширению |
| `input`, `longinput` | — | dmenu-промпт: читает ввод, печатает на stdout |
| `errormsg` | — | модалка с сообщением об ошибке |

Последние три — служебные, их дёргают **другие** скрипты и ждут ответ на stdout.
Пока для них нет замены, rofi из системы не убрать, даже когда лаунчер готов.
Это Фаза 9.

### Что доступно в системе

- **Есть:** `qalc`, `fd`, `rg`, `wl-copy`/`wl-paste`, `hyprctl`, `wtype`,
  `systemctl`, `hyprlock`.
- **Нет:** `cliphist`, `ydotool`, `plocate`.
- **Устарело:** текущий `screenshot` завязан на `flameshot` + `xdotool`
  (X11-наследие), `powermenu` — на `betterlockscreen` и `awesome-client`.
- **Astal-либы:** Apps, Hyprland, Wp, Notifd, Mpris, Network, Bluetooth,
  Battery, Tray, PowerProfiles, Auth, IO + Gtk4LayerShell.

## Фаза 1 — Лаунчер приложений *(≈90%, не закоммичено)*

Заменяет `appslauncher` / `Super + D`.

Готово в [`widget/Spotlight.tsx`](../widget/Spotlight.tsx) и
[`styles/spotlight/_spotlight.scss`](../styles/spotlight/_spotlight.scss):
окно layer-shell поверх всего, карточка в верхней трети, fuzzy-поиск через
AstalApps, ранжирование пустого запроса по `frequency`, клавиатура в
CAPTURE-фазе (Esc / Up / Down / Tab / Enter), мышь (hover двигает тот же
`selected`), fade через пару состояний `mapped` / `shown`, открытие по
`ags request spotlight`.

Осталось:

1. **Переключение раскладки при открытии.** Все rofi-скрипты делают
   `hyprctl switchxkblayout at-translated-set-2-keyboard 0`, иначе поиск не
   работает на кириллице. Тот же вызов нужен в `openSpotlight()`.
2. **Открытие на активном мониторе** вместо `monitors[0]`: создавать окно на
   каждом мониторе и показывать то, чей монитор — `focusedMonitor` у
   AstalHyprland (надёжнее, чем переносить `gdkmonitor` у смапленного окна).
3. **Скролл за выделением:** `selected` может уехать за пределы видимой области
   `scrolledwindow` — нужен `scroll_to` или ручная правка `vadjustment` по
   bounds выбранной строки.
4. Кейбинд `Super + D` → `ags request spotlight`, старый `menu` убрать.
5. Коммит `feat(spotlight): app launcher (phase 1)`.

**Готово, когда:** `Super + D` открывает лаунчер быстрее rofi, Enter запускает,
Esc закрывает, кириллическая раскладка не мешает вводу, rofi-биндинг удалён.

## Фаза 2 — Архитектура провайдеров *(рефактор)*

Превращает Spotlight из «лаунчера приложений» в «оболочку с источниками».
Фундамент: делать до третьего провайдера, иначе `Spotlight.tsx` повторит судьбу
монолитного `style.scss`.

Появляется `lib/` (README его уже обещает, а папки нет):

```
lib/spotlight/
  types.ts       — интерфейсы Provider / SpotlightItem / Action
  registry.ts    — список провайдеров, роутинг по префиксу, сбор результатов
  frecency.ts    — общий рейтинг (частота + давность), JSON в ~/.cache/mybar/
  providers/
    apps.ts      — то, что сейчас лежит внутри Spotlight.tsx
widget/spotlight/
  Window.tsx     — окно, карточка, клавиатура, анимация
  ResultList.tsx — переиспользуемый список строк
  ResultRow.tsx  — строка: иконка / заголовок / подпись / бейдж справа
```

Интерфейс:

```ts
interface SpotlightItem {
  id: string            // ключ для <For>
  icon?: string         // iconName или путь
  title: string
  subtitle?: string
  badge?: string        // правый хвост: "Calc", "Window", "⏎ Copy"
  score: number
  activate(): void      // основное действие
  altActivate?(): void  // Shift+Enter / Ctrl+Enter
}

interface Provider {
  id: string
  prefix?: string          // ">", "=", "w ", "f ", "c " — эксклюзивный режим
  placeholder?: string     // подсказка в поле, когда режим активен
  minQueryLength?: number
  search(query: string, signal: AbortSignal): SpotlightItem[] | Promise<SpotlightItem[]>
}
```

Ключевые решения:

- **Режимы через префикс** (как в Albert/Ulauncher). Пустой префикс — apps плюс
  «дешёвые» провайдеры вперемешку, отсортированные по `score`. Префикс —
  эксклюзивный режим одного провайдера, в поле показывается чип с названием.
- **Асинхронность и отмена.** Файлы и буфер ходят в подпроцесс: дебаунс 60–80 мс
  плюс `AbortSignal`, иначе быстрый набор породит очередь `fd`. Результат
  устаревшего запроса отбрасывается по номеру поколения.
- **Квоты:** в смешанном режиме не больше N строк на провайдера, чтобы файлы не
  вытеснили приложения.

Грабли (см. память проекта):

- Переключение «список ↔ пусто ↔ ошибка» держать на `visible`, **не** на
  `<With>` — иначе поле ввода пересоздастся и потеряет фокус.
- Любой динамический слот внутри строки (бейдж, спиннер) оборачивать в
  статический `<box>`: ре-рендер `<With>`/`<For>` иначе уедет в конец родителя.

**Готово, когда:** поведение Фазы 1 не изменилось, но `apps` — один провайдер из
реестра, а новый провайдер = один файл плюс строка в `registry.ts`.

## Фаза 3 — Калькулятор и запуск команд

Самое дешёвое после архитектуры; даёт мгновенный ответ без «Enter в пустоту».

- **`calc`** — префикс `=` плюс автодетект (строка начинается с цифры или скобки
  и содержит оператор). Бэкенд — `qalc -t`, он уже установлен и умеет единицы и
  валюты: `100 usd to eur`, `2^10 in hex`, `35 c to f`. Результат — одна строка,
  Enter копирует через `wl-copy`.
- **`run`** — префикс `>`: исполняемые из `$PATH` (кэш скана, обновление по
  таймеру). `Shift+Enter` — запуск в терминале (`kitty -e …`), как
  `run-shell-command` в старом `config.rasi`.
- **`ags`** — доступ к собственным IPC-командам оболочки (`quicksettings`,
  `spotlight`); мелочь, но удобно при отладке.

**Риск:** `qalc` при первом запуске тянет курсы валют и может залипнуть на
секунды — вызывать асинхронно с таймаутом ~500 мс, не блокируя список.

**Готово, когда:** `=2+2*10` показывает `22` первой строкой, Enter кладёт в буфер.

## Фаза 4 — Переключатель окон

Аналог `rofi -show window`; на Hyprland полезнее, чем drun.

- Провайдер `windows`, префикс `w ` (в смешанном режиме — под приложениями).
  Источник — `AstalHyprland.get_default().clients`, полностью реактивный, без
  подпроцессов.
- Строка: иконка по `class` (через AstalApps по desktop-entry), заголовок окна,
  подпись `workspace N · class`.
- Действия: Enter — `dispatch focuswindow address:0x…`; `Shift+Enter` — притянуть
  окно на текущий воркспейс (`movetoworkspace`); `Ctrl+W` — закрыть окно, не
  закрывая лаунчер (список перестроится сам).
- Той же ценой: провайдер `workspaces` (переход по номеру или имени) и `hypr`
  (произвольные `dispatch`-команды вроде `togglefloating`).

**Грабля:** после `focuswindow` Spotlight теряет фокус сам — закрывать без
анимации, иначе `keymode = EXCLUSIVE` может съесть первый клик по цели.

**Готово, когда:** три буквы из заголовка + Enter фокусируют нужное окно;
кейбинд `Super + C` с `hyprctl clients` становится не нужен.

## Фаза 5 — Поиск и просмотр файлов

Заменяет `filesearch`, который по сути двухрежимный.

- **Поиск** (префикс `f `): `fd --hidden --exclude .git --max-results 50 <query>`
  по корням `~`, `~/Projects`, `~/Downloads` (список — в конфиге). Дебаунс
  обязателен, `minQueryLength: 2`.
- **Навигация**: запрос, начинающийся с `/` или `~/`, показывает содержимое
  каталога (`Gio.File.enumerate_children`, не `ls`), каталоги первыми. Enter на
  каталоге дописывает путь в поле и остаётся внутри, Enter на файле —
  `xdg-open`, `Shift+Enter` — открыть каталог в файловом менеджере, `Ctrl+C` —
  скопировать путь.
- **Иконки:** не портировать 200-строчный `case` из скрипта. Брать
  `Gio.content_type_guess` → `content_type_get_icon()`, GTK сам найдёт иконку
  темы. Свои `myIcons` — тонким map-оверрайдом сверху, если захочется.
- Опционально: поиск **по содержимому** через `rg` (префикс `rg `) — но это
  отдельный UX со сниппетами, можно отложить.

## Фаза 6 — Менеджер буфера обмена

Сейчас этого нет вообще. Развилка по бэкенду:

| Вариант | Плюсы | Минусы |
|---|---|---|
| **cliphist** (доустановить) | проверенный демон, дедуп, картинки, своя база | внешняя зависимость, парсинг табличного вывода |
| **Свой демон** на `wl-paste --watch` | ноль зависимостей, полный контроль | хранилище, дедуп, обрезку и картинки писать самому |

**Рекомендация — cliphist:** своё хранилище буфера ради чистоты не окупается, на
Hyprland cliphist фактически стандарт.

Состав: провайдер `clipboard`, префикс `c `; строки — превью первых ~120
символов с заменой переносов, бейдж с типом (`text` / `image`), картинки —
миниатюрой в иконке. Enter — `wl-copy` и закрытие; `Shift+Enter` — вставка в
активное окно через `wtype` (только текст, с задержкой после потери фокуса);
`Delete` — удалить запись. Демон (`wl-paste --watch cliphist store`) запускать из
`exec-once` Hyprland, не из ags.

## Фаза 7 — Power-menu и меню быстрых ссылок

Заменяет `powermenu` (`Super + P`) и `appsmenu` (`Super + Return`).

Меняется форма: обе менюшки — **сетки крупных иконок**, а не список. Появляется
вторая раскладка карточки.

- `widget/spotlight/GridMode.tsx` — сетка больших глиф-кнопок, навигация
  Left/Right (плюс `h`/`l`, как было забиндено в rofi), Enter активирует.
- Режим включается не набором текста, а аргументом запроса:
  `ags request "spotlight power"` / `"spotlight apps"` открывают Spotlight сразу
  в нужном режиме и без поля ввода. Значит `toggleSpotlight` получает аргумент,
  а `requestHandler` — разбор подкоманды.
- **Power:** lock / logout / suspend / reboot / poweroff, аптайм в заголовке.
  Команды берём актуальные: `hyprlock`, `hyprctl dispatch exit`,
  `systemctl suspend|reboot|poweroff` — не `betterlockscreen` и не
  `awesome-client` из старого скрипта. Для деструктивных пунктов —
  подтверждение вторым Enter.
- **Apps-меню:** те же пять ссылок, но список — в `lib/spotlight/config.ts`, а не
  хардкодом в `case`. Проверка наличия бинаря — `GLib.find_program_in_path`,
  а не `[[ -f /usr/bin/… ]]`.
- Общее с [`widget/quicksettings/system.tsx`](../widget/quicksettings/system.tsx)
  вынести в `lib/system-actions.ts`, чтобы не дублировать power-логику.

## Фаза 8 — Меню скриншотов

Заменяет `screenshot` (`F11` / `Print`), переиспользует сетку из Фазы 7.

- Пункты: экран / окно / область (опционально «область → редактор»).
- **Смена стека обязательна:** `flameshot` + `xdotool` под Wayland работают в
  лучшем случае частично. Целевой набор: `grim` (снимок), `slurp` (область),
  `hyprctl activewindow -j` (геометрия окна), `wl-copy` (буфер),
  `satty` или `swappy` (редактор). Это доустановка пакетов.
- **Нюанс:** окно Spotlight попадёт в кадр. Нужно закрыть окно и дождаться кадра
  компоновщика (unmap + `timeout ~120 мс`) до вызова `grim` — в скрипте эту роль
  играл `sleep 0.3`.
- Уведомление о готовом файле — через AstalNotifd, с превью.

## Фаза 9 — dmenu-совместимый API *(то, что реально убивает rofi)*

Заменяет `input`, `longinput`, `errormsg` — диалоги, которые вызываются из
**других** скриптов и возвращают текст на stdout.

```
ags request "prompt Название заметки"   # печатает введённый текст на stdout
ags request "prompt-long Текст"         # многострочный ввод
ags request "error Сообщение"           # модалка с одной кнопкой
ags request "menu Выбери:\nA\nB\nC"     # dmenu: печатает выбранную строку
```

Архитектурно интересное здесь — **отложенный ответ** на IPC-запрос:
`requestHandler(argv, res)` не вызывает `res()` сразу, а сохраняет коллбек;
Spotlight открывается в prompt-режиме, `res(text)` (или `res("")` на Esc)
дёргается при сабмите.

> **Проверить в первую очередь:** держит ли Astal сокет открытым до отложенного
> вызова `res`. Если нет — запасной вариант: писать результат во временный
> файл или FIFO, путь к которому передан в запросе, и отдавать `res("ok")` сразу.

Дополнительно: `--dmenu` через stdin, чтобы скрипты могли пайпить список
(`echo -e "A\nB" | ags request menu -`).

**Готово, когда:** `pacman -Rns rofi` не ломает ни один скрипт в
`~/.config/hypr` и `~/.config/rofi/scripts`.

## Фаза 10 — Конфиг, полировка, уборка

- `lib/spotlight/config.ts` — единая точка: провайдеры и их порядок, префиксы,
  корни для поиска файлов, быстрые ссылки, лимиты. Позже — вынести в
  `~/.config/mybar/config.json` с перечиткой по `Gio.FileMonitor`.
- `styles/spotlight/` разбить, когда партиал перевалит за ~200 строк:
  `_card.scss`, `_results.scss`, `_grid.scss`, `_prompt.scss`.
- **Скорость старта:** AstalApps + скан `$PATH` + cliphist на старте ags
  задерживают появление бара — инициализировать провайдеры лениво, при первом
  открытии Spotlight.
- **Фракционное масштабирование** (монитор работает на scale 1.46): проверить
  карточку на 1px-швы. Фон сплошной, так что скорее всего чисто, но строки с
  `.selected` на границах могут дать хайрлайн.
- README: секция про Spotlight, префиксы и IPC-команды; удалить
  `~/.config/rofi` и rofi из зависимостей.

## Порядок и зависимости

```
Ф1 лаунчер ──▶ Ф2 архитектура ──┬──▶ Ф3 калькулятор/run   (внешних зависимостей нет)
   (почти                       ├──▶ Ф4 окна              (только Astal)
    готово)                     ├──▶ Ф5 файлы             (fd — есть)
                                ├──▶ Ф6 буфер             (нужен cliphist)
                                ├──▶ Ф7 power/apps ─▶ Ф8 скриншоты (нужны grim/slurp)
                                └──▶ Ф9 prompt API        ─▶ rofi удаляется
                                                             Ф10 конфиг и уборка
```

Самый короткий путь к «rofi больше не нужен»: **Ф1 → Ф2 → Ф7 → Ф8 → Ф9**.
Калькулятор, файлы и буфер добавляются потом как чистые улучшения.

### Открытые решения

1. **Буфер обмена (Ф6):** ставим `cliphist` или пишем свой демон на
   `wl-paste --watch`?
2. **Скриншоты (Ф8):** переход с `flameshot` + `xdotool` на `grim` + `slurp`
   (+ редактор) — доустановка пакетов.
3. **Ф9:** поддерживает ли `ags request` отложенный `res()` — проверить до того,
